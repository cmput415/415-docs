.. _sec:keywords:

Keywords
========

*Gazprea* has a number of built-in keywords that are reserved and must
not be used by a programmer.

The names of the built-in functions are *not* keywords; they are
reserved semantically rather than syntactically -- see :ref:`sec:builtIn`
for the full rule.

-  and

-  as

-  boolean

-  break

-  call

-  character

-  const

-  continue

-  else

-  false

-  function

-  if

-  in

-  integer

-  loop

-  not

-  or

-  procedure

-  real

-  return

-  returns

-  std_input

-  std_output

-  string

-  struct

-  true

-  tuple

-  typealias

-  var

-  vector

-  while

-  xor
