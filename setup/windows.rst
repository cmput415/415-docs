Windows
=======

The course toolchain is not supported natively on Windows, and no local setup instructions are provided for it. Windows is a fine machine to work *from*: install an SSH client and the X2Go client, and log in to a lab machine, which is the recommended environment for everyone regardless of what they sit in front of. See :doc:`CS Lab Machines <cs_computers>`.

If you would rather have a local Linux environment as well, WSL 2 with Ubuntu will get you most of the way through the :doc:`Ubuntu <ubuntu>` instructions, but it is unsupported and the warning on that chapter applies with extra force: everything that counts is built on a lab machine.
